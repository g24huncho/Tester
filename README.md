# Diverse Paths — Business HQ

Boxing coaching brand by **Gbolan Inakoju**. *Different paths. One destination.*

This repo is the operating system for the business.

## What's here

| Path | What it is |
|---|---|
| `site/index.html` | The brand website / link-in-bio conversion page. Fully self-contained (fonts embedded), mobile-first, SEO-ready. Open it in any browser. |
| `studio/index.html` | **The Corner** — internal HQ: 30-day scripted content plan, weekly filming system, and the Sunday business scoreboard (saved in the browser). |
| `STRATEGY.md` | Positioning, offer ladder, funnel model, 90-day plan, automation roadmap. |

## Using the site

1. Open `site/index.html` — it works from a double-click, no server needed.
2. Before going public, replace the placeholders (all marked in the file):
   WhatsApp number, email, training location, and the example testimonial cards.
3. To deploy: point any static host (Netlify, Cloudflare Pages, GitHub Pages) at
   the `site/` folder and connect a domain.

## Using The Corner

Open `studio/index.html` in your everyday browser (progress and scoreboard data
save locally to that browser — use **Export backup** now and then).

Weekly rhythm:
- **Sunday, 90 min** — batch-film the week using the Filming Day shot list.
- **Sunday, 10 min** — schedule the week's posts in Meta Business Suite using the
  copy buttons on each Fight Plan card.
- **Sunday, 5 min** — log the week's numbers in the Scoreboard.
- **Daily, 5 min** — post the story companion, answer every DM fast.
